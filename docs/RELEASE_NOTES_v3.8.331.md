# Release Notes｜v3.8.331

**发布日期：** 2026-08-21

**发布类型：** GitHub 公开脱敏单文件产品

## 版本概览

Showmath™ — a tour P&L budgeting and scenario simulation tool. v3.8.331 将 Showmath 的完整六步工作流发布为一个可独立运行的 HTML 文件，并同步公开身份、票务、成本、损益、税费、Offer、报告与现金流口径。界面支持中文、英文和西班牙语。

## S1–S6 工作流

1. **S1 项目信息**：整理艺人、团队、票档、价格和基础参数；
2. **S2 演出规划**：安排日期、城市、场馆和演出/行程日；
3. **S3 演出收益**：建立票房、平台费和预计售出情景；
4. **S4 演出成本**：按责任与成本类别管理场馆、制作、人员、酒店、交通、报批、签证、版权及其他费用；
5. **S5 损益结果**：按本场税前利润口径比较 Guarantee、Guarantee + Backend、Door Deal、盈亏平衡与报价敏感性；
6. **S6 汇总方案**：按巡演合并税后口径汇总路线、预算、成本结构、净利润、现金流、关键时间点与 Memo。

## 最终界面与计算稳定性更新

- 六步速览还原真实系统界面，并优化首屏布局与内容层级；
- S1 增加团队共同评估艺人票房潜力示例；
- S2 增加日历活动类型和场馆选择演示；
- S3 增加可编辑的主办方周边净收入，并进入既有 NOR 及后续损益计算链；
- 小屏右侧进度条显示数字 1–6，大屏显示完整步骤名称，均避免覆盖正文；
- 修复币种切换时旧输入被二次换算的问题，往返切换保持原始金额基准；
- S3、S4、S5 城市选择相互独立，可分别保持不同城市。

## 票务与平台费用

- 单票档总票数由 Kills、Holds、Comps 与 Sellable 共同组成；
- Sold 按 `Sellable × 预计售出率` 计算；
- 全部票档总票数与场地容量对照；
- 平台上架 0 张时百分比平台费为 0；
- 平台份额以 Sellable 为分母，上架张数、上架票面金额与平台费即时联动。

## 成本、利润与税费口径

- 直接成本、间接费用和未分类成本保持总额守恒；
- 酒店、城际交通、本地地面交通、签证、版权及其他费用按当前分类进入预算；
- S5 展示单场税前利润与利润率，不新增单城 ROI；
- S6 展示巡演合并税后利润与净利率，综合收益税费不拆分到单个城市；
- 当前默认综合票房预估扣点为 7%；综合收益税负配置合计 32%，由艺人 WHT 5%、境内外包劳务个税 20% 和增值税附加 7% 组成；
- 上述税率均为可调整的预算模拟参数，不作为报税依据；WHT 为付款拆分口径，不重复增加主办方 P&L 成本。

## NBOR 与 Offer

- NBOR 使用总票房收入减双方认可演出成本后的可分池口径；
- 支持统一条款、混合条款与逐场奖金参数；
- 内部 Offer Memo 用于预算决策，对外 Deal Memo 不展示内部利润率与 ROI；
- 支持 Guarantee、Guarantee + Backend、Door Deal、Backend 起征点、单票奖金和票档分成。

## 报告、Excel、Memo 与现金流

- S1–S6 项目报告可在页面内预览；
- 支持项目 JSON 保存/载入、报告 HTML、巡演路线 Excel、预算 Excel、内部 Offer Memo 与对外 Deal Memo；
- 现金流按默认付款与回款时点估算首笔票务回款前的资金缺口；
- Memo PDF/PNG 和 S1–S6 PNG 图片包会按需加载公开 CDN 组件，需要联网；核心产品、HTML 与 Excel 不依赖这些组件。

## 单文件与公开脱敏边界

- 下载 `index.html` 后可在现代桌面浏览器中直接打开；
- Landing 经营数字已模糊，旧的未模糊图片资源不再包含；
- 演示项目为 `The Sold Outs 2027 China Tour`，艺人为 `The Sold Outs`；
- 允许公开的场馆资料和 Agency 名称保留，产品公式、Demo 与导出能力保持完整；
- 仓库不包含非公开源文件、本机目录信息、额外 HTML 副本、验证资产或项目数据档。

## 已知范围与免责声明

- 当前产品以桌面端本地单文件使用为主，不承诺完整移动端编辑体验；
- 图片类导出依赖联网加载的第三方浏览器组件；
- 跨浏览器的文件保存窗口和打印行为可能不同；
- 预算、税费、现金流及 Offer 结果仅用于模拟和方案讨论，不构成真实报价、合同承诺、投资建议、会计意见或报税依据。
