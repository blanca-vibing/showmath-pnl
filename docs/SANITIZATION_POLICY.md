# 公开脱敏版发布规范

本仓库只发布 Showmath™ 的公开脱敏版本。公开版仍是可独立运行的完整单文件产品，不是仅供观看的静态页面。

## 公开边界

- Landing 经营数字已做视觉模糊，旧的未模糊图片资源不进入产品文件；
- 旧身份标识已从最终公开仓库清除；
- 演示项目使用虚构艺人 `The Sold Outs`，项目名为 `The Sold Outs 2027 China Tour`；
- 演示 Agency 使用允许公开的 `WME`，主办方为 `Fullhouse Touring Co.`；
- 场馆资料与允许公开的 Agency 名称可以保留，用于预算模拟和产品体验；
- 产品公式、Demo、S1–S6、三语界面、项目保存/载入及导出功能保持完整；
- 非公开源文件不进入 GitHub 仓库；
- 仓库不包含本机目录信息、非公开 HTML 副本、验证资产、项目数据档或临时产物。

## 发布检查

每次发布前应确认：

1. `index.html` 与获准公开的正式源逐字节一致；
2. 仓库根目录只有一个公开产品入口 `index.html`；
3. 所有公开文档使用一致的版本号、文件名和产品边界；
4. 页面、文档与 Git 暂存内容不含非公开身份、机器目录信息或额外产品副本；
5. Landing 模糊、公开身份、语言切换及 S1–S6 基础流程可正常使用。

公开版中的金额、比例和测算结果用于说明产品能力，不构成真实报价、合同承诺、投资建议、会计意见或报税依据。
