# 公开演示版数据规范

本目录仅用于公开展示演算™的产品界面、交互流程与计算结构。

## 数据原则

- 不使用真实项目、艺人、场馆、机构、联系人、合同、报价或结算资料；
- 页面内出现的名称、城市、路线、日期、金额、比例与成本均为虚构示例；
- 示例金额只说明计算关系，不可作为任何真实项目的报价、采购或决策依据；
- 私下测试包与公开展示包相互独立，公开包不应覆盖或引用私下数据。

## 发布前检查

1. 检查页面、文档和资源文件不含可识别的真实业务信息；
2. 确认所有本地资源可随公开包独立打开；
3. 确认页面底部保留数据用途说明；
4. 新增公开材料时，单独建立带日期与版本号的文件夹。
