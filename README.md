# Showmath™｜巡演损益预算与情景模拟工具

Showmath™ — a tour P&L budgeting and scenario simulation tool. Showmath 面向现场演出与巡演项目，用于组织项目资料、建立票房与成本模型、比较 Offer 结构，并汇总巡演损益、现金流及交付文档。

**当前版本：** v3.8.331（公开脱敏版）

## 在线使用

[打开 GitHub Pages 在线版](https://blanca-vibing.github.io/showmath-pnl/)

也可以下载仓库根目录的 `index.html`，双击后直接在现代桌面浏览器中使用。页面主体、样式、产品逻辑、演示数据和首页图片均包含在这一个文件中，无需安装软件或连接后台服务。

## 六步工作流

1. S1 项目信息：整理艺人、团队、票档与基础参数；
2. S2 演出规划：安排巡演日期、城市、场馆与行程；
3. S3 演出收益：按票档、Sellable、预计售出率和平台费用测算票房；
4. S4 演出成本：管理场馆、制作、人员、酒店、交通、报批及其他成本；
5. S5 损益结果：查看单场税前损益、盈亏平衡、敏感性与 Offer 结构；
6. S6 汇总方案：汇总巡演合并税后结果、路线、预算、现金流、关键时间点与 Memo。

## 主要能力

- 中文、英文、西班牙语界面；
- 票房、平台费、直接成本、间接费用和未分类成本联动；
- Guarantee、Guarantee + Backend、Door Deal 与逐场条款比较；
- 巡演预算矩阵、成本结构、净利润、净利率与现金流测算；
- 项目 JSON 保存与载入；
- S1–S6 报告预览、HTML、Excel、内部 Offer Memo 和对外 Deal Memo；
- 单文件本地运行，不上传用户录入的项目数据。

## 离线与导出说明

核心界面、项目计算、JSON 保存/载入、HTML 文档和 Excel 生成可在本地单文件环境运行。Memo 的 PDF/PNG 导出以及 S1–S6 PNG 图片包会在使用时从 cdnjs 加载 `html2canvas`、`jsPDF` 或 `JSZip`；这些图片类导出需要联网。离线时仍可下载 HTML，或使用浏览器提供的打印能力。

## 公开版说明

本仓库只包含经确认的公开脱敏版本。Landing 经营数字已做视觉模糊，演示身份使用虚构项目；产品公式、S1–S6、Demo、保存及导出能力保持完整。场馆资料与允许公开的 Agency 名称仅用于预算演示和产品体验。

本工具输出仅用于预算模拟与方案讨论，不构成真实报价、合同承诺、投资建议、会计意见或报税依据。实际项目应结合合同、场馆报价、票务规则和专业财税意见复核。
